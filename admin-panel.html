Guide du panneau admin

Le panneau est organisé en 3 zones : ce qui modifie le site public, ce qui pilote l'espace membre, et les messages reçus.

Site public — visible par tous les visiteurs
Actualités — les news de la page d'accueil
Événements — les événements mis en avant sur le site
Installations — courts et infrastructures présentés
Coachs — les fiches des enseignants (⚠ sans rapport avec l'« accès coach » d'un membre)
Tarifs — la grille tarifaire
Partenaires — les sponsors du club (⚠ différent de l'annuaire des partenaires de jeu des membres)
Documents — les PDF téléchargeables
Coordonnées — adresse, téléphone, email du club. L'email est l'adresse qui reçoit le formulaire de contact.
Espace membre — réservé aux adhérents connectés
Membres — créer/modifier les comptes, donner l'« Accès coach » (panneau limité aux Équipes)
Équipes — championnats : équipes, joueurs, calendrier FFT, convocations, discussions
Calendrier — tout ce qui apparaît dans l'onglet Calendrier des membres (tournois, sorties, réunions…). Les matchs d'équipes s'y ajoutent automatiquement.
Messages Club — les annonces du bureau (bandeau « Messages du Bureau » chez les membres)
Reçus
Contacts — les messages envoyés via le formulaire de contact du site
Les 4 procédures courantes
Publier une actu : Site public → Actualités → remplir le formulaire → Enregistrer
Annoncer un événement aux membres : Espace membre → Calendrier → Ajouter (avec la vraie date !)
Lancer un championnat : Équipes → créer le championnat + équipes → les membres s'inscrivent → « Gérer les joueurs » (cocher = valider + assigner) → importer le calendrier FFT → composer et envoyer les convocations
Donner l'accès coach : Membres → fiche du membre → bouton « Accès coach »

Guide du coach — Équipes

Votre panneau gère tout le circuit des championnats par équipes, de la création à la convocation. Les joueurs suivent tout depuis leur espace membre.

Le circuit d'un championnat, dans l'ordre
1. Créer — sous-onglet Championnats : nom, saison, format (simples/doubles), nombre d'équipes avec leurs plages de classement. Les inscriptions sont ouvertes automatiquement.
2. Les joueurs s'inscrivent — depuis leur espace membre, en un clic. Vous les voyez arriver via le bouton « Inscrits » du championnat.
3. Composer les équipes — sous-onglet Équipes → « Gérer les joueurs » : cocher un joueur « En attente » valide son inscription ET l'assigne en une action — il est notifié automatiquement.
4. Le calendrier — bouton « Calendrier » de chaque équipe : saisie manuelle ou import du fichier Excel FFT (les rencontres de Montargis sont détectées automatiquement).
5. Les disponibilités — chaque rencontre du kanban affiche « ✓ dispos · ✗ indispos · ? sans réponse » avec les prénoms, remplis par les joueurs depuis leur espace.
6. Convoquer — « Composer » sur la rencontre : les menus indiquent qui est dispo. « Brouillon » sauvegarde sans notifier ; « Valider & Notifier » envoie la convocation à chaque joueur (par email, notification et push).
7. Suivre les réponses — la tuile affiche « X/Y confirmés » ; un désistement apparaît en rouge avec le nom et vous êtes aussi alerté par email — pensez à recomposer si besoin.
Discussion d'équipe
Le bouton 💬 de chaque équipe ouvre sa discussion (covoiturage, intendance…). Vos messages portent le badge doré « Coach ». Vous pouvez supprimer n'importe quel message si nécessaire.
Bon à savoir
« Fermer les inscriptions » masque le championnat des inscriptions côté membre — les données restent intactes, et c'est réversible.
« Refuser » une inscription demande un motif que le joueur verra ; « Supprimer » retire tout sans message.
Supprimer un championnat efface aussi ses équipes, inscriptions, convocations et discussions — définitivement.
